# VIB Alert — Projet Flutter réel V5.4.2

Ce dépôt contient uniquement l'application mobile VIB Alert et le workflow GitHub Actions qui fabrique automatiquement l'APK Android.

## Compilation

1. Ouvrir l'onglet **Actions**.
2. Choisir **Compiler VIB Alert Android**.
3. Cliquer sur **Run workflow**.
4. Attendre la coche verte.
5. Télécharger l'artefact **VIB-Alert-Android-V5.4.2**.
6. Décompresser le fichier téléchargé pour obtenir `app-release.apk`.

Le workflow reconstruit automatiquement toute la structure Flutter Android/iOS avant la compilation. Il n'est pas nécessaire d'installer Flutter sur le PC.
